TO DO AFOUFA — iPhone version

This is a PWA (Progressive Web App). It stores tasks locally on the device.

To use on iPhone:
1. Put this folder online using any static hosting service.
2. Open the site in Safari on the iPhone.
3. Tap Share -> Add to Home Screen.
4. Open "Afoufa" from the Home Screen.

Features:
- Add tasks and categories
- Complete/uncomplete
- Delete
- All / Active / Done filters
- Progress bar
- Local persistence
- iPhone-friendly design
